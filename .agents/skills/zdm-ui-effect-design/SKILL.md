# 效果图设计与同源开发

先读取 [唯一工作流](../../../docs/ui/effect-design-workflow.md)，按当前阶段执行，不同时开展全部阶段。

- “一份效果图”默认五方案，明确数量优先；后续修改不自动重出五版。
- 展示阶段只做必要结构、样式、模拟数据和关键状态，共享资源，不做五套业务实现。
- 沿用项目 Vue 3、TDesign 与样式环境，允许必要定制布局；专项规范及业务约定不因设计发挥失效。
- 从展示源代码渲染效果图，保存可复现条件；效果图请求仅授权专用设计预览的必要渲染与截图，不访问用户当前标签页。
- 选版后保存准确源文件和图像基准；获得实施授权后直接复用，禁止看图重写或静默改变确认视觉。混合方案先生成合成版确认。
- 交付内容、视觉/业务验收、规范偏离登记与权限边界以唯一工作流为准。只读取当前任务所需规范，不加载无关业务知识。
