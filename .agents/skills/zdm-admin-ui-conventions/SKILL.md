# 装点猫管理后台 UI 约定

## 实施顺序

1. 先读取当前页面、相邻页面和 `@/components/foundation`，沿用已有模式。
2. 当前项目没有合适实现时，只读参考 `管理后台原型基座/zdm-admin-ui`。
3. 新建页面、结构改版或页面类型不明确时，再读取 [模板映射](references/template-map.md) 中最接近的一项。

## 约束

- 实际修改只发生在当前项目，不修改两个只读基座。
- 列表结构、页面头部、分页和弹窗优先复用 foundation 组件。
- 官方模板只参考布局、间距、表格、表单和操作区；业务实现以当前项目为准。
- 小改动不重复读取基座或模板。
