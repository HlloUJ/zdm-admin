# 媒体生命周期与上线核对

## 引用与清理

- BUSINESS：商品、工艺等仍在使用，禁止清理。
- HISTORY：日志引用原文件，最后业务引用解除后保留180天，再缓冲24小时。
- PREVIEW：日志引用独立压缩预览，随日志保留；不延长原文件保留期限。
- MANUAL：人工保留，必须记录设置和解除原因。
- 无引用上传保留24小时。已有媒体解除最后业务引用后，从解除时间计算。
- 重新引用取消到期时间；再次解除后重新计时。
- 实时、每日、失败重试均经过同一个判定器，并锁定媒体行复查引用。
- 历史预览未生成、解码失败或预览物理文件缺失时，继续保护原文件。
- 清理开关默认关闭；未完成迁移不能开启。未知物理文件不自动删除。

## 日志展示

原文件存在时显示原图或视频；原文件到期删除后显示独立历史预览。历史图片可放大预览并提示原图已过保留期；视频只展示封面，不提供失效播放入口。此前已删除且无预览的媒体显示历史媒体已不可用。异常丢失显示媒体暂不可用。

压缩预览长边最多1280px、JPEG质量75%，透明区域白底。WebP通过TwelveMonkeys ImageIO解码（https://central.sonatype.com/artifact/com.twelvemonkeys.imageio/imageio-webp/3.12.0）。视频使用已登记派生封面，缺少封面时保护原视频并记录异常。一个原文件共享一个历史预览，不按日志重复复制。

## 开发环境迁移顺序

1. 使用任务启动器 --database-risk，取得共享库锁并保留SQL备份。
2. V113新增引用类别、历史预览、生命周期开关及人工操作审计；默认关闭物理删除。
3. GET /api/admin/media/audit 核对登记与物理文件。
4. POST /api/admin/media/lifecycle/migrate 重建大板、成品、工艺与大板日志引用。无法确定的解除时间从迁移当天计算；不回溯推断过期。既有多图引用保留。
5. POST /api/admin/media/cleanup 在关闭删除时生成预览并核对清单；GET /api/admin/media/lifecycle 查看原因与时间。
6. 检查异常和候选后，POST /api/admin/media/lifecycle/deletion，JSON包含enabled及reason。以上接口仅超级管理员可用。
7. 人工保护 POST /api/admin/media/lifecycle/hold，JSON包含mediaId、enabled及reason。

暂停只需关闭deletion开关；保留新增引用和预览，不回滚到不识别HISTORY/PREVIEW的旧清理程序。数据库备份不能恢复已经删除的物理原文件。跨任务切换时必须保留本版本清理语义，或停用旧版本清理调度。
