# 验证中断诊断（隔离候选）

只针对原验证器的最新记录及不可变 started 记录，校验路径、attempt 和指纹；若已有绑定 host/worktree/attempt 的 owner 元数据，则只读区分进程仍活跃、已不存在或 PID 已复用。未知归属或检查失败不推断资源已释放。

`diagnoseVerificationInterruption` 无写入；`sealInterruptionDiagnostic` 只以排他创建保存诊断旁文件，不覆盖旧诊断、不写完成结果、不删除锁、不结束进程、不提供重试资格。

当前旧验证器未生成完整 owner/子进程/外部资源证明，本次 921 空锁不能由该候选自动恢复。PID 全部消失也不足以证明浏览器、容器和租约均安全。必须保留原中断失败；根因未知不可声称已修复。此候选没有改变验证器、首次失败规则或真实任务状态，也未启用后台服务。

## 后续隔离生命周期实现

原验证器的命令启动现复用 `completion-process` 的独立 POSIX 监督器。锁内保存主机、工作区、验证器 PID/启动时间、attempt 与指纹；命令启动意图及进程组沿用原监督器证据。新运行写入成功结果前须证明组内前台后代全部退出；异常时保留锁和证据。

`sealEndedVerificationLock` 仅可封存具有完整新格式证明且原所有者已退出、监督器证明所有组已结束的锁，不写门禁成功或自动重试授权。旧空锁仍须单独事后归属审查，不能由该入口编造 owner。当前独立测试验证行为，不是已发布恢复能力。
