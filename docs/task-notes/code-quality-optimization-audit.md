- API 请求统一经 `src/services/http.ts`，由它添加身份凭证、解析响应并处理登录失效；`src/__tests__/http.test.ts` 和 `src/__tests__/sessionExpiry.test.ts` 覆盖关键行为。
- 页面反馈统一使用 `src/components/foundation/feedback/adminFeedback.ts`。成品现货三端和大板双端的失败提示含有不同操作、状态与权限语义，因此保留具体文案，不把所有 `catch` 合并成通用提示。
- 本次抽取两组相同的列表筛选与排序实现。门店成品现货按自己的商品和状态模型筛选，保持独立实现。

## 后端校验边界

- 控制器继续负责入口权限及请求边界；商品写入、日志读取和大板发布引用等职责已在本批次移至对应服务。
