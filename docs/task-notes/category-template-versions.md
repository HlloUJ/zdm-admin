## 当前功能目录登记（2026-09-09）

商品管理 → 商品公共基础数据 → 分类属性模板页 → 成品现货模板 / 配件模板。
每个 Tab 仅登记查看（view）、创建新版本草稿（create）、版本记录（history）。
create 同时控制创建、继续编辑、草稿内全部编辑与自动保存、发布，以及既有展示顺序调整；前后端使用同一权限。
history 控制版本记录及历史版本读取；仅 view 可查看最新已发布版本，不能读取草稿或历史版本。
原 save/publish/discard 和细分操作不再作为可分配条目，未自动扩大既有角色与终端授权。

版本记录的查看后增加复制操作，沿用 create 权限，不另设目录权限。复制已发布版本的完整 content 和 change_note 到单一草稿，原版本保持不变。已有草稿需确认覆盖并携带草稿 id/revision；并发变化拒绝覆盖。复制后进入草稿继续编辑，发布时沿用递增版本及配置校验。
