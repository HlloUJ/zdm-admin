## 实施边界

- 仅成品现货：供应链下架、删除至回收站或彻底删除，使现有运营记录及门店记录永久失效；运营对应操作仅使门店记录失效。
- 上游重新上架不恢复旧记录。记录留在原 Tab，显示失效原因；保留详情、日志和单个彻底删除入口，其他业务操作由后端拒绝。
- 商品 ID 不变。同一门店在旧记录彻底删除前不能重复选择；通过来源行锁及事务内全记录检查串行化选择，不依赖发布批次过滤。
- 重新选择采用当前规格和价格，旧人工销售价格不继承。历史日志按门店及商品 ID 检索，保留不同内部记录 ID 和历史快照；订单模块不做改动。
- 供应链恢复早于运营删除时，运营彻底删除失效记录后沿用已有自动入仓机制，重新生成当前指导价和级别价格。普通运营回收站彻底删除保持原行为。
- 普通编辑、调价、库存变化不新增失效触发；大板业务规则不变。不跨项目。
