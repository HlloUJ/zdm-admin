# 门店端全局样式标准检查

2026-10-16，按用户授权检查门店端，沿用既有八类标准，不另建门店专用规范。

| 检查范围                             | 结果及处理                                                                                                                                                                                                                                               |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 成品现货列表、商品中心、操作日志     | 查询复用公共布局；补齐两处商品分类占位文案；商品中心操作栏接入AdminListToolbar，删除旧工具栏与已选数量样式。原权限、选择和日志入口保持不变。                                                                                                             |
| 门店商品编辑                         | 保留已有业务分区、只读商品信息、规格与价格矩阵，继续使用公共表单、SpecPriceInput和校验反馈。                                                                                                                                                             |
| 成品现货／配件价格及折扣配置         | 查询按钮接入公共右对齐动作区；折扣列表接入公共操作栏；清理无使用方的输入框宽度样式。价格系数保留72px紧凑输入框、正常57px行高及原规则；正常输入框垂直居中，系数列提供完整提示所需宽度。按用户后续确认，仅报错行临时增加一行错误提示高度，修正后恢复57px。 |
| 客户管理、新增编辑、跟进及归属弹窗   | 跟进时间和下次跟进时间占位文案补全为“请选择日期时间”。普通单列弹窗480px；跟进为已批准的720px复杂表单，通用附件保留原实现。                                                                                                                               |
| 供应商、门店分类、角色、员工共用页面 | 继续引用公共查询、操作栏、字体、表单宽度及校验实现；本轮未调整共用业务页面，不改变其他端。                                                                                                                                                               |

检查覆盖查询、占位文案、列表操作栏、字体、表单布局、媒体上传、校验反馈、普通单列弹窗八类。没有图片／视频独立上传的门店页面不新增上传功能；富文本和通用附件不迁移。权限矩阵、批量设置、下架操作、预览与详情沿用登记的专用布局。

占位守卫补充门店复合选择控件与原生enable-time-picker识别；价格回归验证错误完整可见、正常行高57px与输入框居中、仅报错行增高且修正后恢复，并沿用原API与交互断言。
