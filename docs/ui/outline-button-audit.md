# 全平台描边按钮与禁用态核对（2026-10-19）

## 核对范围与结果

- 源码中30处固定 `variant="outline"`，以及租户业务开通选项的1处动态 `base`／`outline`；数量是模板位置，公共组件可生成多个业务按钮。
- 覆盖运营、供应链、门店页面，登录／员工邀请验证码、公共列表辅助操作、权限全选／清空、历史版本、日志、规格操作、价格配置批量设置，以及公共上传按钮入口。
- 所有普通描边动作继续通过原有 `buttonTheme` 功能映射取主题；业务开通选项保留已登记的原生主题与选中态切换。
- 附件上传和价格批量设置已使用官方 `disabled` 属性，保留上传中／满3附件、加载中／保存中／未选可编辑分类等原禁用表达式。未发现普通描边动作通过透明度或仅拦截点击伪装禁用的实现。
- 未发现普通描边按钮禁用文字、图标、边框或背景的自定义配色覆盖。

## 实际清理

员工邀请页 `.item-container :deep(.t-button)` 仍显式覆盖 `border-radius`，虽使用官方变量，仍属于冗余按钮皮肤覆盖。本轮仅从原组合选择器中移除按钮一项，由 TDesign 官方组件决定圆角；原输入框／单选控件样式不变。验证码按钮116px布局宽度、主题、倒计时、禁用与加载表达式、各步骤及全部请求处理均保持原样。

未改变任何按钮形式、主题、权限、事件或禁用条件，无需新增功能变更确认。价格跟随模式、规格／分类选项、图片视频预览面属于既有登记专用控件，保持其原有状态与交互；不以普通描边按钮标准重做。上传区域已有内部样式依赖维持本批次先不改的约定。
