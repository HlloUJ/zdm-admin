# 抽屉全局样式规范

状态：2026-10-23用户确认，并在完整检查后确认补齐抽屉分类、正文、宽度及旧规范适用边界。覆盖运营端、供应链端、门店端及其他现有和后续业务端。以后新增或调整抽屉默认必须遵守本规范，只有用户明确提出特殊要求时才允许例外。

规范确认阶段只更新规范，不修改页面代码。规范确认、既有迁移记录和实际页面实现是三个不同层次，不得据此声称存量页面已全部符合补充后的标准；页面调整按后续明确授权实施。

## 所有抽屉共用的容器规则

统一使用TDesign原生Drawer，默认从右侧打开。通过官方公开属性和插槽实现，保留官方遮罩、边框、字体、颜色、间距及动效；不另做抽屉皮肤，不通过自定义CSS、内联样式、内部类覆盖或主题变量重绘官方视觉。官方组件无法表达的必要业务布局按全局UI规范处理，不构成另设皮肤的授权。

- 结构由顶部标题栏、中央内容区和按用途显示的底部操作栏组成。标题和底栏不随正文滚动；正文超高时在原生内容区滚动，不额外嵌套整层滚动容器。
- 标题只在原生顶部栏出现一次，正文不重复展示同名标题。
- 不默认增加副标题或说明栏。确有必要的说明放在相关内容附近；范围说明、字段提示等有业务作用的内容不因去除重复标题而一并删除。
- 保留顶部原生关闭入口。关闭按钮、遮罩及ESC使用原生能力；已有未保存提醒、关闭限制等业务保护继续保留，不因样式统一而绕过或移除。改变这些业务行为须另有明确授权。

## 按用途确定操作位置

| 类型                           | 默认操作栏与正文规则                                                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 编辑、填写及整体业务操作       | 整体提交或操作放在原生底部栏，不放在正文顶部；默认右侧抽屉底部靠左，主操作在前、取消在后。保留校验、加载、禁用、权限和关闭保护             |
| 只读、详情查看                 | 不新增保存按钮；底栏可隐藏，已有底部“关闭”可保留。查看、预览等局部操作留在对应内容附近；只读不代表正文免于样式检查                         |
| 查询、操作日志、版本记录等列表 | 查询与重置保留在查询区，行级详情、复制等操作保留在对应行；不将这些局部操作移到底部。按是否存在整体提交决定底栏，正文执行全局查询和列表规范 |

同一抽屉切换编辑与只读模式时，复用同一容器，按原有模式和权限条件显示操作栏与字段状态，不复制两套皮肤，也不更改模式切换规则。

### 编辑和整体操作按钮

- 新增使用“确认新增”，编辑使用“确认保存”，业务操作使用“确认＋操作名称”；批量操作按全局执行按钮命名约定保留“批量”。主题使用既有功能映射。
- 默认右侧抽屉不得为模仿Dialog而改成按钮右对齐或交换顺序。字段旁的新增、删除等局部操作保留在对应字段附近。
- 取消关闭抽屉，不提交本次填写。校验失败时保持抽屉打开，并按全局表单校验反馈标准展示错误；不因改用原生确认事件而绕过校验或提前关闭。

## 宽度、控件与局部滚动

- 普通内容使用原生默认抽屉宽度；普通控件填满所属布局分配的区域，按表单规范处理，不另设固定窄字段宽度。
- 多列表单、规格／价格矩阵、日志和详情等复杂内容可以通过官方size属性适当加宽，但抽屉宽度不得超出视口；不将某个页面的宽度作为全局默认，不覆盖内部容器类来限制宽度。
- 内容确需横向滚动时，将滚动限制在矩阵、表格等必要的局部区域；保留其固定列、全屏和对照功能。不得以此替换原生抽屉正文滚动，或让整个抽屉超出视口。
- 统一宽度不授权修改既有字段列数、顺序、业务列宽及数据含义。用户明确批准的特殊尺寸按具体例外记录执行。

## 正文分区与复杂业务内容

普通分区使用原生Card、Typography、Descriptions等官方组件及现有公共标题入口的默认外观。不为抽屉自绘灰底标题、背景、边框、圆角或分区间距；商品与大板详情也执行同一要求。分区标题与抽屉顶部标题职责不同，保留“图文描述”“基础信息”“销售信息”等必要业务分区，不删除或改名。

价格矩阵、历史变更对照、媒体展示及其全屏、预览等复杂内容保留业务结构和能力，不因统一外观删减功能。保留这些布局不等于保留另一套分区皮肤；普通分区外观仍按上述规则执行。商品富文本及历史内容排版继续遵守既有专项例外，不套用普通界面文字的排版规则。

## 例外记录、旧规范与实施边界

- 本规范覆盖所有业务端，不按运营、供应链或门店采用不同默认布局。新增或调整前核对真实共享使用方，不新增其他端不存在的业务入口。
- 特殊要求必须来自用户的明确批准，并记录具体抽屉或组件、特殊要求、批准依据及适用范围；只在该范围生效，不扩散为全局默认。
- 历史代码、自定义样式、已存在的宽度、旧迁移快照或“方便实现”不能自动成为例外。
- 旧规范中“日志／弹窗暂保留”“详情自定义分区暂保留”的历史范围说明，不再作为本次确认范围内抽屉的样式豁免；查询提示和普通详情分区按本规范及其引用的当前规则执行。矩阵、历史对照、媒体与业务交互的保留约定继续有效，不因此扩大其他页面的改造范围。
- 规范更新与页面迁移分别记录。按当前任务授权实施；只有规范更新授权时不修改页面。任何实施都保留未获授权改变的字段、顺序、权限、接口、数据、校验及业务处理。
- 实施后逐项验证标题唯一、正文与局部滚动、宽度边界、按钮区域与顺序、只读与编辑模式、查询提示及原提交、取消和关闭保护，不能只检查抽屉外壳。
