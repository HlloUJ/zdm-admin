# 全局控件占位文案标准

适用运营端、供应链端、门店端现有及未来模块，覆盖查询、创建、编辑、批量填写、弹窗、日志和表格内控件。此标准只规范空值提示，不改变字段标题、默认值、校验、选项、查询范围、权限或事件。

## 唯一规则

| 控件                             | 占位文案                                                         | 示例                                         |
| -------------------------------- | ---------------------------------------------------------------- | -------------------------------------------- |
| 文本、数字、金额、系数、多行输入 | 请输入＋现有标题                                                 | 姓名→请输入姓名；长度（mm）→请输入长度（mm） |
| 下拉、多选、级联、树选择         | 请选择＋现有标题                                                 | 产地→请选择产地                              |
| 单日期／日期时间／时间           | 请选择日期／请选择日期时间／请选择时间                           | 与控件现有选择类型一致                       |
| 日期范围／时间范围               | 请选择开始日期／请选择结束日期，或请选择开始时间／请选择结束时间 | 分别对应两个端点                             |

- 标题只去掉前置必填星号及末尾冒号；单位、括号及其他文字保留。组件自动绘制的星号和冒号不属于标题。
- 不推断业务含义，不补充名称、ID、编号等范围，不增删“名称”等字词。普通字段修改标题时同步调整提示；查询中的组合搜索字段按下述统一规则执行。
- 表格控件使用对应列或已有子字段标题，不使用外围“销售规格”等分区标题。动态属性使用实际属性标题。
- 没有独立标签的既有登录、规格、选项控件使用其现有字段名称；不要为了提示改动可见标题或布局。
- 格式示例、长度、数量、取值限制等原说明保留在原生 `help`／`tips` 中，不混在占位文案中；既有业务说明、错误提示不改写。
- 只读展示、身份切换器、文件上传以及内部透传输入组件不强制添加编辑提示；外层可编辑调用方负责传入正确提示。

## 实现和维护

静态标题显式填写提示，便于审查；动态标题统一使用 `src/utils/controlPlaceholder.ts` 的 `controlPlaceholder(title, 'input' | 'select')`。公共 `AdminListPage` 和 `ProductOperationLogTemplate` 已接入。禁止运行时扫描 DOM、猜测标签或推断搜索范围。

`npm run check:ui-templates` 包含全系统占位文案守卫，随现有前端 source-guards 执行。新增页面必须沿用相同规则；守卫拒绝有标题的普通控件使用“请输入”“请选择”或标题不一致的提示。表格内和无独立标签的业务控件同样需提供标准提示。

本轮迁移保持原业务契约指纹；经用户明确批准的占位属性、帮助文案位置和辅助函数导入以独立精确补丁记录，其他差异继续受原保护约束。

## 查询组合搜索字段

作为查询全局标准的一部分，组合搜索使用短标题及完整范围提示，例如标题“大板”、提示“请输入大板名称/ID/编号”。范围由业务配置明确提供，不自动猜测。公共入口使用 `ListFilter.searchScope`，兼容页面使用 `data-query-search-scope`；仅适用于查询输入，不可用于编辑表单或选择控件绕过普通规则。完整映射和接入方式见 [查询全局标准](./query-standard.md)。
