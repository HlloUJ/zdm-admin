# 表单、批量填写与上传外观全局标准

状态：2026-10-15登记商品表单、批量填写与上传外观；2026-10-19按用户确认方案补齐全平台新增、编辑表单通用规则。本次只整理规范，不修改代码或改变既有页面布局、业务规则和交互。

## 通用规则与引用层级（2026-10-19确认）

本节适用于全平台现有及新增的创建、编辑表单。字段专项规范只引用本节，不复制标签、宽度、字体、占位文案和错误提示规则。专项只补充该类控件特有行为；经明确批准的专项例外只在其授权范围生效，不扩散到其他控件。

| 项目           | 通用规则                                                                                                                                                                                                                                                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 标签布局       | 按所属表单类型及已登记布局执行。普通单列弹窗使用现有公共Form／FormItem的标签布局和冒号；整页、多列、顶部标签以及已批准的特殊表单保留原布局，不一律改成右对齐。标签列宽按所属表单标准，不由单个控件另定。                                                                                                                            |
| 必填标记       | 根据已有必填条件，在可见字段标题前显示TDesign官方红色星号；原生rules由FormItem生成，手工或动态必填通过公开required-mark表达。动态标记同步原必填条件，不从星号反推或新增校验。无可见标题的登录、验证码、选项快捷输入保留原布局；不得为了星号新增标题。规格／价格表已有必填标记置于列标题前，保留原条件和官方错误色，不改变表格结构。 |
| 控件宽度       | 普通控件填满所属布局分配的控件区域（100%，不超过容器），不单独写死宽度。普通单列弹窗按下文登记标准执行；整页、多列、规格／价格／权限矩阵及已登记的紧凑组合控件保留其分配区域和必要例外，不改变原列数、顺序、响应式断点。                                                                                                            |
| 字段间距       | 普通纵向表单按官方24px字段间距安排；提示占位属于这份间距预算，不能再叠加一行空白。普通字段栅格按下文24×32px规则执行；查询和已批准特殊布局分别引用自身规范。末项及弹窗内边距按公共布局处理，不为凑24px给末项追加外边距。                                                                                                             |
| 字体与组件外观 | 引用[全局字体标准](./typography-standard.md)，字体、颜色及组件的背景、边框、圆角、悬停、聚焦、禁用、只读和错误状态沿用TDesign官方样式，不在控件专项中重复规定数值或重绘皮肤。                                                                                                                                                       |
| 占位文案       | 引用[全局占位文案标准](./placeholder-standard.md)，不在字段专项中重复维护文案规则。                                                                                                                                                                                                                                                 |
| 错误提示与空间 | 引用[全局表单校验反馈标准](./form-validation-standard.md)的“错误提示承载”与“提示空间与字段间距”；本节不维护第二套提示布局。                                                                                                                                                                                                         |
| 业务边界       | 保留现有标题、字段值、必填条件、校验规则及触发、权限、API、保存和取消交互。专项已明确批准的变化按该专项执行，不能借统一外观扩展其他业务行为。                                                                                                                                                                                       |

上层规范的集中登记和公共展示接入由实施方负责，不要求用户决定校验接线等技术细节。用户确认可见效果和规则后，在授权范围内实现并验证；发现确需改变未授权业务行为时，再说明具体影响。整理规范本身不授权改变既有页面。

## 唯一实现和官方依据

- 公共表单布局：`src/components/foundation/official/product-form-layout.css`，由全局样式入口导入。禁止各端维护另一套标题、普通字段和批量填写间距；上传组直接使用原生Space。
- 上传实现：公共 `AdminMediaUpload` 原生卡片，按 `docs/ui/media-upload-standard.md` 执行。新业务媒体上传复用该组件；不得复制上传事件或为接入样式重写媒体业务逻辑。
- 官方来源在 `official-sources.json` 登记：Starter `form/base/index.less`、TDesign 原生 Form、Card、Tag 和 Upload 样式。参考版本保持不变；不修改上游快照。
- 官方没有与装点猫完全相同的批量填写业务模板；这里保留业务布局，组合 Card body、Form 和 CheckTag 的官方视觉，不能称为整页原样模板。

注意：官方 `--td-comp-margin-xl` 的实际值为20px；此前讨论写成16px已纠正。标题间距以官方基础表单变量为准。

## 固定规则

| 区域         | 标准                                                                                                                          |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| 表单分区标题 | 官方基础表单：18px／26px／400；外边距上24px、左右0、下20px                                                                    |
| 普通字段栅格 | 纵向24px、横向32px，保持原有字段顺序、列数及响应式断点；直接子表单项底部间距为0，防止与栅格重复叠加                           |
| 批量填写区块 | 使用原生 Card body 的上下16px、左右24px内边距，官方背景、边框及圆角                                                           |
| 批量字段     | 使用同一24×32px栅格间距；已有五列是批量编辑业务布局，不套用查询最多四列规则                                                   |
| 范围选择标签 | 使用原生 Tag／CheckTag 的高度、内边距、圆角和小号正文字体；未选outline，选中primary light-outline，保留原多选、全部及切换事件 |

上传统一使用原生组件，具体尺寸、间距、标题、视频封面、校验及适用边界见 [图片与视频上传全局标准](./media-upload-standard.md)。旧的自绘上传皮肤、上传网格和重复说明已被替代。

## 已登记商品表单与上传布局的适用边界

- 覆盖供应链、运营成品现货和大板中对应编辑区域，以及公共媒体上传组件的既有使用方。门店没有大板管理，不新增模块。
- 公共类不依赖页面 `.admin-layout` 祖先，兼容弹窗挂载到body的场景。普通表单使用 `.form-grid`，存量大板 `.dialog-form-grid`／`.dimension-grid`／`.corner-grid` 在商品表单范围兼容同一规则；不扩大到详情对照、只读Descriptions及其他矩阵。
- 商品富文本、媒体文件、缩略图内容和裁切方式、上传限制、权限、接口、表单校验、提交／取消、滚动导航、批量匹配和保存规则保持不变。
- 查询区域继续遵守查询全局标准；标题与操作栏、字体继续遵守各自全局标准。

## 验证与后续模块

新增模块通过公共入口和公共CSS消费上述规则，不用页面局部覆盖恢复旧值。源码守卫验证唯一实现、官方快照、间距、上传尺寸和公共组件接入；回归继续验证原上传／预览／删除、批量填写和编辑流程，不通过改业务预期接受样式迁移。

## 普通单列新增、编辑弹窗宽度

2026-10-15用户确认：普通单列新增／编辑弹窗统一使用TDesign默认Dialog宽度480px、Form标签列100px，普通文本、数字、下拉、级联、日期及多行文本控件填满所在控件区（100%，不超过容器）。控件本身继续使用原生样式；多行文本的高度管理及字数统计位置按[多行文本框专项规范](./textarea-standard.md)的官方属性与已批准例外执行。该规则是统一官方组件配置，不意味着TDesign规定所有页面输入框都必须固定相同像素宽度。

唯一控件布局在 `product-form-layout.css` 的 `.zdm-admin-single-form` 实现。新模块使用 `AdminFormDialog`，默认获得该标记；存量兼容弹窗通过同一标记接入，原生Dialog公开width属性设置480px。各页面不得再为普通单列编辑表单保留360／440／520／560／620／640／720px等独立宽度，或在内部另设窄表单。标签列统一100px。

覆盖清单登记在 `official-sources.json` 的 `singleColumnFormStandard.forms`，当前27个普通表单实例（含门店级别编辑及客户新增／编辑跟进），共享页面同时覆盖使用它的业务端。商品发布等整页、多列业务表单、SKU／价格／权限矩阵、选项列表管理、批量操作、预览和详情保持各自业务布局；查询区继续使用查询标准。标题、字段、文案、模型、校验、权限、事件及提交／取消不变。

复查守卫按实际Form／输入控件扫描全部页面弹窗，不仅按“新增／编辑”标题或已有清单检查。普通弹窗登记后验证480px及公共类；直接复用默认AdminFormDialog的表单自动符合标准；特殊操作、查询、矩阵和多列表单按有原因的excludedForms登记，避免误改，也防止漏掉标题不含“编辑”的单字段编辑弹窗。

## 国际区号与号码组合字段

客户联系方式使用公共`AdminPhoneInput`，由原生InputGroup与两个原生Input组成：左侧80px只读国际区号始终使用原生禁用灰底，右侧填写号码，组合总宽度填满控件区。该尺寸仅用于表达只读区号与号码的必要业务布局；不覆盖原生字体、颜色、边框、高度或内边距。外层表单标签、必填及错误消息继续由原生FormItem和既有字段反馈提供。国籍与号码地区使用原生可搜索单选Select。

## 控件专项规范

多行文本框遵守[多行文本框专项规范](./textarea-standard.md)。该专项引用本文件及公共字体、占位文案、校验反馈标准，只维护多行文本特有的长度、自动增高、拖动和字数统计规则，不在此重复维护专项条款。
