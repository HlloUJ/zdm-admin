# 表单、批量填写与上传外观全局标准

状态：2026-10-15 用户批准将检查清单前四项统一；未来模块遵守。只调整样式，其他详情卡片、规格／价格／权限矩阵、价格来源开关及既有交互不在本次范围。

## 唯一实现和官方依据

- 公共表单布局：`src/components/foundation/official/product-form-layout.css`，由全局样式入口导入。禁止各端维护另一套标题、普通字段和批量填写间距；上传组直接使用原生Space。
- 上传实现：公共 `AdminMediaUpload` 原生卡片，按 `docs/ui/media-upload-standard.md` 执行。新业务媒体上传复用该组件；不得复制上传事件或为接入样式重写媒体业务逻辑。
- 官方来源在 `official-sources.json` 登记：Starter `form/base/index.less`、TDesign 原生 Form、Card、Tag 和 Upload 样式。参考版本保持不变；不修改上游快照。
- 官方没有与装点猫完全相同的批量填写业务模板；这里保留业务布局，组合 Card body、Form 和 CheckTag 的官方视觉，不能称为整页原样模板。

注意：官方 `--td-comp-margin-xl` 的实际值为20px；此前讨论写成16px已纠正。标题间距以官方基础表单变量为准。

## 固定规则

| 区域         | 标准                                                                                                                          |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| 表单分区标题 | 官方基础表单：18px／26px／400；外边距上24px、左右0、下20px                                                                    |
| 普通字段栅格 | 纵向24px、横向32px，保持原有字段顺序、列数及响应式断点；直接子表单项底部间距为0，防止与栅格重复叠加                           |
| 批量填写区块 | 使用原生 Card body 的上下16px、左右24px内边距，官方背景、边框及圆角                                                           |
| 批量字段     | 使用同一24×32px栅格间距；已有五列是批量编辑业务布局，不套用查询最多四列规则                                                   |
| 范围选择标签 | 使用原生 Tag／CheckTag 的高度、内边距、圆角和小号正文字体；未选outline，选中primary light-outline，保留原多选、全部及切换事件 |

上传统一使用原生组件，具体尺寸、间距、标题、视频封面、校验及适用边界见 [图片与视频上传全局标准](./media-upload-standard.md)。旧的自绘上传皮肤、上传网格和重复说明已被替代。

## 适用边界

- 覆盖供应链、运营成品现货和大板中对应编辑区域，以及公共媒体上传组件的既有使用方。门店没有大板管理，不新增模块。
- 公共类不依赖页面 `.admin-layout` 祖先，兼容弹窗挂载到body的场景。普通表单使用 `.form-grid`，存量大板 `.dialog-form-grid`／`.dimension-grid`／`.corner-grid` 在商品表单范围兼容同一规则；不扩大到详情对照、只读Descriptions及其他矩阵。
- 商品富文本、媒体文件、缩略图内容和裁切方式、上传限制、权限、接口、表单校验、提交／取消、滚动导航、批量匹配和保存规则保持不变。
- 查询区域继续遵守查询全局标准；标题与操作栏、字体继续遵守各自全局标准。

## 验证与后续模块

新增模块通过公共入口和公共CSS消费上述规则，不用页面局部覆盖恢复旧值。源码守卫验证唯一实现、官方快照、间距、上传尺寸和公共组件接入；回归继续验证原上传／预览／删除、批量填写和编辑流程，不通过改业务预期接受样式迁移。

## 普通单列新增、编辑弹窗宽度

2026-10-15用户确认：普通单列新增／编辑弹窗统一使用TDesign默认Dialog宽度480px、Form标签列100px，普通文本、数字、下拉、级联、日期及多行文本控件填满所在控件区（100%，不超过容器）。控件本身的边框、内边距、字体、高度继续使用原生样式。该规则是统一官方组件配置，不意味着TDesign规定所有页面输入框都必须固定相同像素宽度。

唯一控件布局在 `product-form-layout.css` 的 `.zdm-admin-single-form` 实现。新模块使用 `AdminFormDialog`，默认获得该标记；存量兼容弹窗通过同一标记接入，原生Dialog公开width属性设置480px。各页面不得再为普通单列编辑表单保留360／440／520／560／620／640／720px等独立宽度，或在内部另设窄表单。标签列统一100px。

覆盖清单登记在 `official-sources.json` 的 `singleColumnFormStandard.forms`，当前26个普通表单实例（含复查补齐的门店级别编辑），共享页面同时覆盖使用它的业务端。商品发布等整页、多列业务表单、客户跟进的两列附件表单（通过AdminFormDialog的formLayout=custom保留720px）、SKU／价格／权限矩阵、选项列表管理、批量操作、预览和详情保持各自业务布局；查询区继续使用查询标准。标题、字段、文案、模型、校验、权限、事件及提交／取消不变。

复查守卫按实际Form／输入控件扫描全部页面弹窗，不仅按“新增／编辑”标题或已有清单检查。普通弹窗登记后验证480px及公共类；直接复用默认AdminFormDialog的表单自动符合标准；特殊操作、查询、矩阵和多列表单按有原因的excludedForms登记，避免误改，也防止漏掉标题不含“编辑”的单字段编辑弹窗。

## 国际区号与号码组合字段

客户联系方式使用公共`AdminPhoneInput`，由原生InputGroup与两个原生Input组成：左侧80px只读国际区号，右侧填写号码，组合总宽度填满控件区。该尺寸仅用于表达只读区号与号码的必要业务布局；不覆盖原生字体、颜色、边框、高度或内边距。外层表单标签、必填及错误消息继续由原生FormItem和既有字段反馈提供。国籍与号码地区使用原生可搜索单选Select。
