# 多行文本框专项规范

状态：2026-10-19用户确认最终分层方案；现有24处可编辑多行文本框已完成100字符、框内统计及官方对象形式autosize接入，只读邀请链接保持。实施范围与验证证据见[全平台核对记录](./textarea-feedback-audit.md)，规范登记与代码迁移状态分别记录。

## 上层规则引用

- 标签布局、必填标记、控件宽度和字段间距：[表单通用样式规范](./form-style-standard.md)。沿用所属表单类型，不从客户样板复制整套弹窗宽度和标签列宽。
- 字体与官方组件外观：[全局字体标准](./typography-standard.md)及表单通用规则。
- 占位文案：[全局占位文案标准](./placeholder-standard.md)。
- 错误承载、一次提示占位及报错前后布局：[全局表单校验反馈标准](./form-validation-standard.md)。

以上规则不在本专项重复定义。当前“新增跟进—跟进内容”用于核对可见特征，不把该字段的必填、提交逻辑或所属表单布局推广为其他字段的业务要求。

## 多行文本特有规则

| 项目           | 统一规则                                                                                                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 基础组件       | 使用TDesign官方Textarea。                                                                                                                                                                    |
| 默认上限       | 新增和现有可编辑多行文本框默认统一最多输入100个字符，显示官方统计；存量未设置上限的输入字段同样适用，特殊上限须另行明确。                                                                    |
| 长度与计数     | 通过官方maxlength限制输入并显示原生统计，默认配置为100，沿用官方计数、粘贴和中文输入法处理，不自绘统计或重写计数。已有明确使用maxcharacter的字段须核对既有计数含义，不能机械替换为不同口径。 |
| 初始及后续高度 | 开启官方对象形式autosize，由组件根据内容计算高度。不用CSS固定56px；56px仅是未开启自动增高时的官方默认高度参考，不是自动增高模式的固定初始高度。                                              |
| 自动增高范围   | 使用官方对象形式autosize，不额外指定未经确认的初始行数、最大行数或像素高度。默认接入可使用空配置对象，由官方默认算法处理；不将此前未确认的“初始3行、最多6行”写入实现。                       |
| 手动拖动       | 对象形式autosize沿用官方禁止手动拖动行为，由组件统一管理高度，不另加resize皮肤。                                                                                                             |
| 内容溢出       | 默认未设置最大行数时继续自动增高，不额外制造固定高度的内部滚动区域。今后如明确批准最大行数，再使用官方属性及原生滚动处理，不能裁切或遮挡内容。                                               |
| 统计位置       | 使用官方原生统计，统一放在输入框内右下角，保持官方字体和颜色。                                                                                                                               |
| 防遮挡         | 预留必要内容空间，统计不遮挡正文或原生滚动条；增高后仍保持在输入框右下角。                                                                                                                   |
| CSS授权边界    | 仅允许统计定位及防遮挡留白所需的必要CSS，统一由公共实现承载，不在各页面复制。该位置是项目授权定制，不冒称官方原生位置属性；不借此改写其他外观或错误布局。                                    |
| 输入操作       | 支持原生换行、粘贴和中文输入法处理，遵守已确认的输入上限及业务交互。                                                                                                                         |
| 历史内容       | 不自动截断历史内容；超过新默认上限的历史值如何编辑另行明确，不能默默丢失原值。                                                                                                               |
| 只读展示       | 不作为可输入字段补加100字符限制或截断展示内容；保留已有复制、选择和展示交互，不自动套用编辑行为。                                                                                            |

官方属性接入示意：

```vue
<t-textarea v-model="value" :maxlength="100" :autosize="{}" />
```

示意只表达默认长度和官方自动增高配置，不替换各字段原有标题、错误来源、事件及业务绑定。统计布局继续由公共实现承担；当前参考实现为src/components/foundation/official/textarea-count-layout.css，其与官方autosize计算协同已通过专项回归，后续修改仍需验证。

## 执行与验证边界

实施方负责规范集中登记与公共展示接入，用户确认可见效果和规则，无须决定技术接线。除本次明确确认的默认上限和高度管理方式外，保留原业务规则、权限、校验及触发、错误清除、保存和取消；确需其他业务变化时另行说明并确认。

后续实施检查各业务端的初始高度、输入和删除内容后的自动增高／收缩、无拖动手柄、统计定位及防遮挡、字段间距、错误提示与合法保存。覆盖窄屏、长内容和历史超长值，不以修改业务测试预期接受未经授权的行为变化。

官方依据：[TDesign Vue Next Textarea](https://tdesign.tencent.com/vue-next/components/textarea)，项目登记参考版本1.20.2；本次不升级依赖。
