# 列表批量选择全系统核查

依据：2026-11-04 用户确认[列表批量选择规则](list-standard.md#列表批量选择)，先落规范，再检查和调整存量。适用于运营、供应链和门店端，以及未来新增模块。

## 调整清单

| 业务端 | 模块/列表                  | 调整                                                              |
| ------ | -------------------------- | ----------------------------------------------------------------- |
| 供应链 | 成品现货管理               | 所有Tab的选择列、计数及失效选择共用有效批量能力                   |
| 供应链 | 配件管理                   | 通过商品页面复用接入相同规则                                      |
| 供应链 | 大板管理                   | 所有Tab按有效批量能力显示选择列                                   |
| 运营   | 成品现货管理               | 所有Tab的选择列、计数及失效选择共用有效批量能力                   |
| 运营   | 配件管理                   | 通过商品页面复用接入相同规则                                      |
| 运营   | 大板管理                   | 所有Tab按有效批量能力显示选择列                                   |
| 门店   | 成品现货管理               | 所有Tab按有效批量能力显示选择列，保留商品中心选择用途             |
| 门店   | 配件管理                   | 通过门店商品页面复用接入相同规则                                  |
| 门店   | 客户管理                   | 公共AdminListPage按当前Tab的批量能力显示原生选择列并清理失效选择  |
| 门店   | 价格配置－成品现货价格系数 | 原本已有权限显隐；统一公共能力，补齐权限/分类切换后的失效选择清理 |
| 门店   | 价格配置－配件价格系数     | 同一价格配置入口的另一分类，按相同规则处理                        |

商品列表覆盖全部、仓库中、已上架、已售完及回收站。只有仓库删除授权时仓库可选择、全部不可批量删除；仅清空回收站不显示选择列；有有效批量权限但零选中或处理中仍保留选择列。客户覆盖日常/归档状态。价格系数两个分类共用`/store/price-configuration`入口，不增加菜单或模块。

## 核查范围与保留项

- 全量扫描`src`的Vue页面、模块包装器和业务组件，核对原生multiple选择列、selected-row-keys及表格中的复选框；基础公共实现单独验证。配件路由包装器复用三端成品页面，按实际模块分别列入清单。
- 分类属性模板的添加属性、选项值弹窗属于业务选择；门店商品中心弹窗同属业务选择，保留原复选框、选择事件和确认流程。源码检查只允许准确文件/列名且处于弹窗内的已登记用途，不按整个文件豁免。
- 权限矩阵、登录记住账号、订单表单选项、查询复选条件属于表单/配置用途；价格配置折扣系数及其他无行选择列的列表无需新增复选框或批量功能。
- 不修改功能目录、权限编码/归一化、组织/数据范围、API、后端事务、状态流转、商品来源限制及批量确认/结果反馈。

## 公共实现与防遗漏

`AdminListPage`默认按显式`batch: true`动作管理原生选择列。兼容页面复用`useListBatchSelection`，通过同一权限过滤后的操作配置控制选择列、计数及失效选择；不根据disabled或按钮标签推测。源码守卫扫描当前与未来Vue表格，业务选择例外限定准确对象。
