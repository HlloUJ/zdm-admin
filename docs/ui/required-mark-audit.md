# 全平台必填标记核对（2026-10-19）

本轮只统一既有必填标题的星号展示，删除门店下架详细说明的“选填”文案，不新增必填条件或修改校验器、字数上限、权限、数据范围、保存及状态操作。

## 核对范围与依据

检查src全部Vue的Form／FormItem、原生rules、自定义校验拒绝入口、动态商品／销售属性，以及规格和价格表的标题渲染器。原生Form规则中的required由TDesign自动生成星号，不能仅凭模板未写required-mark判定缺失；动态字段沿用field.required，查询条件、只读说明和批量操作中允许留空的字段不增加星号。无标题的验证码／选项快捷输入保留既有布局，不新增标题。
