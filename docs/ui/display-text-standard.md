# 名称、标题与编号展示标准

状态：2026-10-22 用户确认的项目公共交互与样式约定。TDesign Link 是可选组件用法，不构成名称或标题应可点击的官方要求。

## 统一规则

- 普通业务记录的名称、姓名、标题、订单号及其他编号仅作文本展示，不承担查看详情、编辑、跳转或展开操作。使用普通文本节点或 `span`、`strong` 等展示元素，不包装为 Link、按钮或可点击容器。
- 不为展示文本绑定 click、双击、Enter／Space 等操作事件，不增加 `role="link"`、`role="button"`、操作焦点、指针光标或链接悬停效果；不能仅改颜色而保留隐藏点击行为。
- 查看详情使用独立且明确标注的“详情”入口；权限条件、事件函数、数据范围、禁用态、接口及详情内容继续消费原有逻辑。不能因为名称改为文本而新增、扩大或删除权限。
- 名称和标题沿用所在区域的原生字体及主文字色 `--td-text-color-primary`。需要醒目的标识沿用官方 `--td-font-mark-medium` 等既有强调层级，不使用品牌蓝暗示可点击，不硬编码颜色、字号或字重，不新增公共皮肤。
- 复制编号、编辑、预览等明确操作保留独立按钮／图标及其原有权限、无障碍标签和交互，不扩大文本点击区域。

菜单、Tab、树节点、分类／属性选择项等本身具有导航或选择语义的控件，以及已登记的附件预览／下载入口，保留其官方控件和原有交互；它们不属于普通业务记录的展示字段。不得以这些专用操作为由把记录名称或编号重新做成详情链接。

## 开发与验证

新增和修改模块统一遵守本文件。模板中名称／标题单元格、业务标识插值及其父容器由 `scripts/display-text-policy.mjs` 检查，源码守卫纳入 `check:ui-templates`。守卫同时覆盖 Vue 模板的点击／键盘／链接语义和常用 `h` 渲染入口，独立“详情”操作及原生选择控件继续允许。

验证须确认：点击展示文本不触发详情；独立详情入口仍按原权限显示并打开原内容；无详情权限时姓名／编号仍可展示、详情操作仍不可用；复制等独立操作保留。不得通过全局事件拦截、CSS `pointer-events` 或强制覆盖颜色绕过语义修复。

本次仅迁移客户姓名及销售订单卡片编号，保留其他业务逻辑和布局。旧编号点击专用指针样式随入口删除；客户列宽、订单号位置、字号和强调字重不变。
