# 列表页标题与操作栏全局标准

状态：2026-10-15 用户验收供应链成品现货试点后批准全局推广。使用 TDesign 原生 Row、Space、Button；区域组织是项目全局约定，不冒称官方模板原样复刻。

## 唯一入口

新增列表使用 `@/components/foundation` 的 `AdminListPage`，既有兼容页面统一使用 `AdminListToolbar`。不得另写一套操作栏。查询区继续遵守 [查询全局标准](query-standard.md)，控件文案遵守 [占位文案标准](placeholder-standard.md)。

## 固定规则

- 去掉页面顶部仅展示当前页面名称、路径的标题／面包屑栏。不为没有 Tab 的列表增加空白标题行。
- 保留顶部品牌、身份切换、侧栏菜单、状态 Tab 及原生底部分隔线；保留编辑页返回、关闭、分区标题与业务导航。
- 表格上方操作栏左侧保留新增、发布、批量等原业务按钮与顺序；右侧放已有操作日志入口。无日志功能的页面不得新增入口；不能因无左侧按钮而隐藏有权限的日志入口。
- 操作日志使用原生 `t-button theme="default" variant="outline"`，不覆盖背景、颜色和边框；保留原权限条件、点击函数和弹窗／抽屉交互。
- 已选数量紧跟左侧批量按钮，只有当前权限和状态下存在逐项选择的批量操作，且选中数量大于 0 时显示。判断权限而不是按钮 disabled 状态；零选中、无批量操作权限、只有新增／发布／清空回收站等非选择操作时均不显示。
- 依赖勾选数据的批量操作保留显示，零选中时禁用；选中后仍保留原有权限、归属、数据有效性及处理中限制。点击处理函数保留空选择校验作为防护。单条与批量操作不因本规则改变颜色。
- `AdminListPage` 对显式标记 `batch: true` 的操作统一追加零选中禁用，兼容页面及选择弹窗在原按钮上配置相同条件。清空回收站等不依赖勾选的操作、允许清空选项集合的提交和自带范围的规格批量填写不套用此规则。
- 不改变复选框、选中集合、跨页选择、批量处理、数据范围和确认逻辑。不为展示计数清空或修改选择。
- 按钮使用原生尺寸及 Space small 间距；保留查询末行到操作栏 24px、原表格区域间距。没有操作内容的公共操作栏不渲染。
- 没有普通行选择的专用价格编辑器、权限矩阵、详情／编辑分区及弹窗内部业务工具区保留原布局，不套用列表计数规则。

## 接入契约

`AdminListPage.actions` 传入已按当前权限和状态过滤的操作；逐项选择批量操作明确配置 `batch: true`，其余不配置。`selectedCount` 传原有选中数量。已有日志等辅助操作通过 `auxiliaryActions` 传入，继续消费原 `action` 事件，不创建新业务功能。

兼容入口 `AdminListToolbar`：`hasActions` 表示左侧存在可见操作，`hasBatchActions` 表示过滤后存在逐项选择批量操作，`selectedCount` 传原有数量；`hasAuxiliary` 表示右侧存在可见操作，原日志按钮放 `#auxiliary`。空操作栏不占用一行。禁止按按钮文案猜测权限或批量含义。

## 本次迁移与验证

全系统主页面移除展示型标题栏；供应链／运营成品现货、大板及门店成品现货共五处已有全局日志入口置于操作栏右侧。客户及上述商品列表的已选计数统一由公共入口控制；其他页面不新增日志或计数功能。编辑表单、上传预览、原有权限和事件保持。

公共组件单测覆盖计数为零、正数、撤销批量权限、仅日志及点击事件；源码守卫禁止主页面恢复顶部标题栏，并检查五处日志复用公共操作栏。后续新增模块必须使用相同入口和规则。

按钮功能颜色统一遵守 [UI规范中的按钮功能与颜色](standard.md#按钮功能与颜色2026-10-16确认)，逐项选择规则和原有业务契约保持。

## 窄屏列表容器兼容（2026-10-22）

经用户明确授权的存量列表越界修复统一复用 `official/responsive-layout.css`：页面使用 `zdm-admin-responsive-page`，列表弹窗通过 `dialog-class-name` 使用 `zdm-admin-responsive-dialog`，抽屉宽度按[抽屉全局样式规范](drawer-standard.md)通过原生Drawer公开size属性限制在视口内，不再要求版本记录抽屉使用旧的 `zdm-admin-responsive-drawer` 内部容器覆盖。页面和列表弹窗仍仅在991px及以下解除存量页面最小宽度、约束弹窗视口边界；商品编辑分区使用可收缩的单列容器，表格继续使用原生横向滚动。保留桌面尺寸、业务列宽、字段、权限、查询及分页事件，不复制局部皮肤。

列表中的名称、标题、姓名及编号按[展示文本标准](display-text-standard.md)呈现，详情保留独立且受权限控制的操作入口；不改变列宽、布局及其他行操作。
