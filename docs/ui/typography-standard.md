# 全局界面字体标准

状态：2026-10-15 用户批准统一全系统界面字体，未来新增模块遵守。字体依据为登记的 TDesign Vue Next 1.20.2 与 Starter 0.14.0；只调整字体样式，保留业务、交互与富文本。

## 官方来源与唯一数值来源

- 字体变量：`official-sources.json` 登记的官方 `es/style/index.css`。直接消费 TDesign 变量，禁止新增一套项目字号、行高或字重变量，禁止覆盖 `--td-font-*` 和 `--td-line-height-*`。
- 表单分区标题：官方 `src/pages/form/base/index.less` 的 `.form-basic-container-title`，采用 `font: var(--td-font-title-large)` 后设置 `font-weight: 400`。顺序不可颠倒，避免 font 简写重置字重。
- 普通控件、表格、Tab、菜单、弹窗标题继续使用原生组件规格，不用通配选择器统一压成14px。

## 各层级使用规则

| 用途                               | 统一声明                                             | 当前官方规格      |
| ---------------------------------- | ---------------------------------------------------- | ----------------- |
| 全局正文、普通说明                 | `font: var(--td-font-body-medium)`                   | 14px / 22px，常规 |
| 次级说明、ID、时间等辅助信息       | `font: var(--td-font-body-small)`                    | 12px / 20px，常规 |
| 正文强调、规格组标题、分类层级强调 | `font: var(--td-font-mark-medium)`                   | 14px / 22px，600  |
| 小字强调、价格来源标记             | `font: var(--td-font-mark-small)`                    | 12px / 20px，600  |
| 自定义详情分区、日志卡片标题       | `font: var(--td-font-title-medium)`                  | 16px / 24px，600  |
| 商品表单分区标题                   | `font: var(--td-font-title-large); font-weight: 400` | 18px / 26px，常规 |
| 页面主标题、登录及统计展示         | 使用对应官方 title / headline 变量                   | 按原有层级保留    |

全局字体族与 Starter reset 一致：`-apple-system, BlinkMacSystemFont, var(--td-font-family)`；原生组件自身字体族不覆盖。保留官方抗锯齿设置。图标的 `font-size` 可使用对应官方字号变量，不能把图标当正文修改。

## 约束与富文本边界

- 用完整字体变量同时确定字号、行高、字重和字体族；强调文字不用散落的500／600／700数值覆盖。已有图标字号及字体继承可继续使用官方变量或 inherit。
- 仅需要行高时使用对应的 `--td-line-height-*`；不得把14px正文另压成20px，或用1、12px等临时行高。
- 只允许官方基础表单的18px标题明确设400；详情标题的16px／24px／600本身符合官方规格，应归一到完整 title-medium 变量，不能误改成正文。
- 不使用全局 `*`、`button`、`h1` 等强制字体覆盖；不改变高度、内外边距、宽度、颜色、定位和交互。
- 商品富文本HTML、编辑器字号／字体／行距功能、用户输入内容、历史富文本预览排版全部保留。历史富文本组件现有1.5及空段0.5行高属于明确保留内容，不纳入后台界面文字迁移。

## 公共实现与未来模块

基础正文由 `src/styles/index.css` 管理；已有公共商品表单样式和详情组件直接消费官方变量，不为各端复制字号数值。新增模块遵循相同语义层级，使用公共页面及原生组件，不新增局部字体皮肤。

`check:ui-templates` / `test:source-guards` 检查全系统字体声明：禁止硬编码字号、字重、行高、自建字体变量或字体族；校验官方变量真实存在、表单标题为18px常规字重，并保留明确的富文本例外。原业务契约校验继续独立执行。
