## 视觉标准

- 字体使用官方body-medium及字体栈；body次级文字色、全局antialiased；不改写td主题变量。
- Tab沿用官方3px指示线和原生颜色/尺寸；不改Tab顺序、文案与状态。
- 列表容器按common-table使用上下/左右xxl内边距32px、medium圆角6px；移除自加阴影、外边框及首末列加宽padding。
- 查询按common-table栅格实现：条件区与按钮区原生10:2比例，外层不额外扣除gap；内层每项占4/12，采用左右12px列内边距和行容器左右-12px外边距，行gutter24px，表单项保留官方24px下边距。筛选列表标签统一80px、右对齐；输入框宽100%、最小宽134px。日志抽屉查询亦采用80px标签、列gutter和表单项下边距，但保留日期跨列、按钮位置及既有窄屏排列。现有事件、字段顺序与占位文案不变。
- 原有分组查询保留主次行。大板宽屏可显示5列，较窄时3列（不切换为窄屏单列）；按钮留在次行右侧。已有条件分组与各Tab字段保持不变。
- 表格保持原有列配置，移除强制左对齐及字号覆盖，恢复原生Table行为。分页保持原事件、页码及页大小；外置分页沿用原事件入口，区域采用原生Table分页的上下/左右l内边距16px，不叠加24px外边距。规格表已有bordered属性保留，边框与表头背景使用原生Table，不覆盖单元格边框。
- 按钮保留原variant、图标、文案、顺序、权限、禁用条件和事件。原棕色批量下架按钮使用原生warning主题，原深红危险按钮使用原生danger主题，移除背景/边框覆盖，由组件统一普通、悬停、按下及禁用视觉。业务动作配置脚本不改。
- 普通列表操作链接的横向间距参照common-table默认Space，为16px；纵向间距、flex-wrap和white-space保持原配置。客户页已确认的small间距、商品专用操作区和分类拖拽树表等业务布局保留，不用全局选择器覆盖。查询及工具栏按钮的8px间距不受此项影响。
- 分类属性模板的Tree选中外观沿用原生组件：背景及圆角由标签区域绘制，不额外给整个节点行铺设背景。选择、展开、筛选及左右区域布局保持不变。
- 标准AdminDialog默认宽度480px，与原生Dialog一致；页面显式设置的宽度保持不变。标准编辑表单标签统一100px，包括原72px及92/96/116px配置；客户跟进等已有长标题专用配置和无对应模板的业务布局保留。上传、预览、全屏、拖拽、只读与失效遮罩保留原工作方式。
