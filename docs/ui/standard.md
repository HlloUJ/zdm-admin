`check:ui-templates` 同时校验官方快照、所有前端业务契约和新页面入口约束。原legacy指纹仍保留；只有已批准清单内的文件可迁移，不重新生成旧指纹掩盖行为变化。新增文件仍受原规则约束。

每轮只更新已批准的视觉测试断言，不修改业务预期。最终候选运行完整适用门禁、零跳过零重试。默认不进行人工浏览器验收，用户通过5175查看效果。

控件占位文案统一遵守 [全局占位文案标准](./placeholder-standard.md)：输入框“请输入＋标题”，选择控件“请选择＋标题”；保留单位，不推断搜索范围。动态标题使用 `controlPlaceholder`，新增模块必须通过占位文案守卫。

查询组合搜索字段统一使用短标题和显式配置的完整范围提示（公共入口 `ListFilter.searchScope`），属于查询全局标准；普通字段规则不变。保留80px标签列和24px间距，不自动推断或扩展搜索能力。

列表标题与操作栏必须遵守 `docs/ui/list-standard.md`：不设展示型页顶标题栏；复用公共列表操作栏，既有日志右置，已选数量在左侧批量按钮后且仅有批量权限并选中大于0时显示。不新增日志功能，保留编辑导航及业务交互。

全系统界面字体遵守 `docs/ui/typography-standard.md`：直接使用官方完整字体变量，表单分区标题按官方基础表单18px常规字重，强调文字用mark变量；禁止新增硬编码字号、字重及行高。保留原生组件字体层级和商品富文本内容、编辑与预览排版。

表单分区间距、普通字段栅格、批量填写及上传外观遵守 `docs/ui/form-style-standard.md`，统一复用公共 `product-form-layout.css` 与 `AdminMediaUpload`；标题上24／下20px，普通字段24×32px，上传框110×110px。保持原有列数、全部业务事件及其他业务定制，不复制页面皮肤。

独立图片、视频上传必须使用 `@/components/foundation` 导出的 `AdminMediaUpload`，遵守 [媒体上传全局标准](./media-upload-standard.md)。原生卡片与Space为唯一实现；富文本及通用附件保留原入口，不改必填、权限和媒体生命周期。

新增、编辑和动态表格的字段校验必须遵守 [全局表单校验反馈标准](./form-validation-standard.md)：错误红框＋字段下方具体提示；原生Form规则优先，既有手工状态复用 `utils/formValidation.ts`。所有表单提交校验失败统一调用 `utils/submitValidation.ts`：只弹一次“表单校验未通过，请检查标红字段”，同时显示全部字段错误并自动定位首错；输入和失焦不弹Toast、不滚动。提交失败、网络异常及非字段操作前置提醒保留Toast，不替代字段提示，不修改现有规则。
