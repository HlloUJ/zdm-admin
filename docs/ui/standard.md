## 视觉标准

- 字体使用官方body-medium及字体栈；body次级文字色、全局antialiased；不改写td主题变量。
- Tab沿用官方3px指示线和原生颜色/尺寸；不改Tab顺序、文案与状态。
- 列表容器按common-table使用上下/左右xxl内边距32px、medium圆角6px；移除自加阴影、外边框及首末列加宽padding。
- 查询使用官方栅格思路：普通条件区与按钮区10:2，条件每行3列，间距24px，按钮间距8px并靠右；现有事件绑定和占位文案不变。客户页保留已确认80px标签，其余标准表单使用原生100px标签以容纳长字段。
- 原有分组查询保留主次行。大板宽屏可显示5列，较窄时3列/1列；按钮留在次行右侧。已有条件分组与各Tab字段保持不变。
- 表格保持原有列配置，移除强制左对齐及字号覆盖，恢复原生Table行为。分页保持原事件、页码及页大小，区域间距24px。
- 按钮继续原有theme/variant、图标、文案、顺序和权限；自定义棕色、深红改用官方warning/error色，不引入新颜色。
- 标准弹窗表单使用原生标签尺寸；长标题和复杂编辑允许原有公开尺寸配置。上传、预览、全屏、拖拽、只读与失效遮罩保留原工作方式。
